◆ authType

LudeoAuthType LudeoSessionActivateCallbackParams::authType

Tells what authentication type the SDK used for the session activation.

This has a valid value only if resultCode is LudeoResult::Success. If the client specified an explicit authentication, it will be set to what the client specified. If the client didn't specify an explicit authentication, the SDK will deduce an authentication type from the current environment and this will be set to that authentication type.

The most common scenario in which this is useful is if the client needs to know if it is running in the cloud.

◆ ludeoSelected

LudeoBool LudeoSessionActivateCallbackParams::ludeoSelected

If as part of the session activation the SDK detected that a ludeo should be played, this is set to true.

When this is true, the SDK guarantees that soon after this callback, a LudeoSelected notification is received.
