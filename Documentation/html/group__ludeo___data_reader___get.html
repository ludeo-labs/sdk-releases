Detailed Description

Functions to get gameplay state take an attributeName, destination pointer, and return LudeoBool to indicate success or failure.


The value is retrieved according to the current context stack ( see ludeo_DataReader_EnterObject and ludeo_DataReader_EnterComponent )

Most primitive data types are supported, and also some complex ones. More will be added in the future as necessary.

◆ ludeo_DataReader_GetString()

LudeoBool ludeo_DataReader_GetString ( const char * attributeName,
char * outValue )

Gets a string attribute.

Important
The NULL character is NOT copied, and it's the client's responsibility to correctly terminate the string. When reading strings, the client should first do a call to ludeo_DataReader_GetSize to get the string size and make sure the buffer provided to this function is big enough. After the call, the client can then null terminate the string since it knows the size.
