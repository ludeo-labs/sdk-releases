◆ appToken

const char* LudeoSessionActivateParams::appToken

Backend app token to activate if available.

It can be nulled.

Normally, this will cause the backend to signal the SDK that it should play a Ludeo, which will cause the ludeoSelected field in the callback parameters struct will be set to true, and a LudeoSelected notification will occur.

◆ authDetails

void* LudeoSessionActivateParams::authDetails

Pointer to one of the Ludeo<NAME>AuthDetails structs or nulled.

If nulled, the SDK will try to automatically deduce authentication based on the current platform/environment. For example, on Platforms that support Steam, the SDK will check if the Steamworks dll is loaded and attempts to retrieve the user information. Note that the SDK doesn't initialize Steamworks (or any other supported provider). That's the responsibility of the client. If the client didn't initialize any of the supported providers (e.g: Steamworks), then authentication will fail with LudeoResult::InvalidAuth.

Explicit authentication details allows working around any unforeseen problems with either the SDK or client design, if for some reason the SDK can't retrieve the required information. Also useful during development or for testing scenarios where e.g Steam might not be running.

◆ gameVersion

const char* LudeoSessionActivateParams::gameVersion

The game version string.

Can not be nulled or an empty string if apiVersion is 3 or higher.

Used to identify for each ludeo what are the compatible game versions that can play it.

◆ localization

LudeoSessionSetLocalizationParams* LudeoSessionActivateParams::localization

Localization settings to apply.

This can be nulled, in which case the SDK will use default settings (english).

This does exactly the same thing as calling ludeo_Session_SetLocalization. The reason it can also be provided as part of the Session Activation is so the Overlay starts with these settings.

◆ reset

LudeoBool LudeoSessionActivateParams::reset

If true, it will reset the attributes and actions the backend has for the game.

This should only be used during early development.

This functionality is only available for some environment, to keep the client from accidentally reseting a live game.

Warning
Use this with care, as it will invalidate all existing ludeos and some other settings. If unsure, contact us first.

◆ windowHandle

void* LudeoSessionActivateParams::windowHandle

The client's window handle (Native OS handle) that should be used for the SDK's overlays and video recording.

It can be nulled. If this is null, overlay and video recording will be disabled
