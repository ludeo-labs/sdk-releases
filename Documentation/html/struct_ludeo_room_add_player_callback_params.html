LudeoHGameplaySession LudeoRoomAddPlayerCallbackParams::gameplaySession

GameplaySession handle to use for the player.

If any error occurred, then this will be null.

The lifetime of this handle is tied to the lifetime of the owning Room. Any handles not destroyed when the room is destroyed will be destroyed and invalidated automatically.
