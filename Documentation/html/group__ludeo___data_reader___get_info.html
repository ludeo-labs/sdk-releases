Returns information related to the Ludeo the DataReader represents.

Check the LudeoDataReaderInfo struct for what information is available.

Parameters
handleThe interface handle.
paramsParameters to the function
outIf LudeoResult::Success is returned, then on exit this will contain a pointer to the information.
Returns
If LudeoResult::Success, then the "out" parameter will contain a pointer to the information.
Important
Once done with the information, the client should call ludeo_DataReaderInfo_Release to release the struct.
