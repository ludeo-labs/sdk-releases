LudeoBool ludeo_DataReader_GetStorageSize ( const LudeoDataReaderGetStorageSizeParams * params,
uint32_t * outSize )

Looks for the specified key in the storage and returns its size in bytes.

This allows the client to query the size of storages for which it needs to pre-allocate memory. E.g, when reading back a dynamic string.

Parameters
paramsStruct with any parameters to the function
outSizeSize of the data in bytes.
Returns
True if the attribute was found at the current level, in which case outSize will contain the size.
