◆ ludeo_Session_Activate()

void ludeo_Session_Activate ( LudeoHSession handle,
const LudeoSessionActivateParams * params,
void * clientData,
LudeoSessionActivateCallback callback )

Activates a session.

The client should call this after creating the session and registering to all the notifications. While not technically required to register to notifications before calling this, some notifications can happen as the result of calling this function and therefore might be missed by the client.

Parameters
handleThe interface handle.
paramsParameters to the function.
clientDataContext that will be passed to a callback
callbackCallback to call once the operation completes
Warning
At the moment, if this call fails, the client should NOT attempt to call this a second time. If the client wishes to retry the activation, it should destroy the session with ludeo_Session_Release and attempt activating a second session.
