◆ loggingCallback

LudeoLogCallback LudeoInitializeParams::loggingCallback

Sets the logging callback function as part of initialization.

If null, then it is going to be ignored. Any logging done by the SDK will be forwarded to the specified function. Avoid expensive operations from the callback, such as directly logging to a file.
