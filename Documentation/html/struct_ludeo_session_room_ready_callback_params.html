LudeoHRoom LudeoSessionRoomReadyCallbackParams::room

Handle of the room this notification refers to.

Note that this is NOT a new handle. It's the handle to an existing room the client created.

Even if the client only has 1 room at a time, it should still validate if the notification is for the room it expects. This can avoid bugs related to a callback being in the queue for execution but when the client handles the callback that room is no longer relevant. If the client needs to query other info about the room, it can use the ludeo_Room_GetInfo function.
