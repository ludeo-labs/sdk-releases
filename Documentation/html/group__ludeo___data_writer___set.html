Detailed Description

Functions to set gameplay state take an attributeName and value and return LudeoBool to indicate success or failure.

The value is set according to the current context stack ( see ludeo_DataWriter_EnterObject and ludeo_DataWriter_EnterComponent )

Most primitive data types are supported, and also some complex ones. More will be added in the future as necessary.

const uint8_t * data,

Set a binary blob attribute.

Blob attributes provide a way for the client to save any arbitrary data, which makes it a very flexible tool to leverage serialization code the client might already have for game objects, but note that care must be taken not to over-rely on blobs, since even if a single byte changes (compared to the previous value), the entire blob needs to be sent, which can cause bandwidth problems.

Parameters
attributeNameattribute name.
datapointer to the blob data. If the size parameter is 0, then this is allowed to be null.
sizeSize of the blob in bytes.
Returns
LUDEO_TRUE on success, LUDEO_FALSE on failure.
Remarks
If the room that created this DataWriter was opened to play a ludeo (see ludeo_Session_OpenRoom and LudeoSessionOpenRoomParams), this function performs no action and immediately returns LUDEO_TRUE.
Therefore, as an additional optimization at the client level, the client should avoid creating blobs when in ludeo playing mode, as doing so results in unnecessary CPU usage for something that is thrown away.
