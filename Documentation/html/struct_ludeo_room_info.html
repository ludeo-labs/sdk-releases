Detailed Description

Information that can be retrieved with the ludeo_Room_GetInfo function.

Any pointers in this struct points to the SDK's internal memory, and therefore the client should not keep hold of them. As soon as the client gets the information, it should copy what it needs before making any other calls to the SDK.
