Detailed Description

The DataReader interface encapsulates the concept of ludeo data.

As-in, it contains all the information related to a specific ludeo, such as the necessary data to restore the game state.

The lifetime of a DataReader instance is tied to the Session lifetime. When a session is destroyed, any DataReader handles created as part of that Session are invalidated, although the client should call ludeo_DataReader_Release when it has no further need for the ludeo data.

A typical flow is the client gets hold of the DataReader it needs for a particular Ludeo, and keeps reusing while the player keeps playing the same Ludeo. Once the player wishes to go back to the main menu, then a call to ludeo_DataReader_Release should be done to free up the resources.

◆ ludeo_DataReader_EnterObject()

LudeoBool ludeo_DataReader_EnterObject ( LudeoObjectId objectId)

Pushes an object to the context stack.

Any ludeo_DataReader_XXX calls to read data will act on this object, until ludeo_DataReader_LeaveObject is called.

Typically a client will first make a call to ludeo_DataReader_GetObjectsInfo to read back all the object ids and their types. With that information the client instantiates all the game objects it needs (of the right type) and assigns the LudeoObjectId to each instance to match the Ludeo data. Once that is done the client can then query the data to deserialize every object by using this function as the starting point for each object.

Parameters
objectIdObject to use.
Returns
True if successfully entered the object (the object exists), or False if the object doesn't exist.
Important
For every successful call to this function, there must be a counterpart ludeo_DataReader_LeaveObject call to unwind the context stack.

◆ ludeo_DataReader_GetSize()

LudeoBool ludeo_DataReader_GetSize ( const char * attributeName,
uint32_t * outSize )

Looks for the specified attribute in the current context and returns its size in bytes.

This allows the client to query the size of attributes for which it needs to pre-allocate memory. E.g, when reading back a dynamic string.

Parameters
attributeNameName of the attribute to query.
outSizeSize of the attribute in bytes. If the attribute is a string, this is the size of the string in bytes, excluding the null character. E.g: If the string is empty, this will be 0.
Returns
True if the attribute was found at the current level, in which case outSize will contain the size.

◆ ludeo_DataReader_LeaveObject()

This should only be called after a successful call to ludeo_DataReader_EnterObject.

Returns

◆ ludeo_DataReader_Release()

LudeoResult ludeo_DataReader_Release ( LudeoHDataReader handle)

Releases the specified DataReader instance, freeing any resources.

DataReader instances lifetime are tied to the Session they were created from and are automatically destroyed when the session is destroy, but the client should call this when it has no further use for a Ludeo, in order to free the resources.

Parameters
handleThe interface handle.

Any attempt to use the handle after this call will fail.
